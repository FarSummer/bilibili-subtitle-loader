# bilibili-subtitle-loader

一个篡改猴（Tampermonkey）脚本，让你可以在 B 站视频页面加载本地的 ASS / SRT 字幕文件。

## 功能

- 在 B 站视频页面的工具栏中添加一个"加载字幕"按钮
- 支持加载本地 `.ass`、`.srt`、`.vtt` 字幕文件
- 字幕会跟随视频播放进度自动显示
- 不依赖 B 站账号，纯本地运行

## 安装

1. 确保浏览器已安装 [篡改猴（Tampermonkey）](https://www.tampermonkey.net/) 扩展
2. 下载脚本**[点击安装](https://FarSummer.github.io/bilibili-subtitle-loader/B站本地字幕加载器-1.3.user.js)**
3. 将脚本拖入篡改猴控制面板界面

## 使用

1. 打开任意 B 站视频页面（`www.bilibili.com/video/...`）
2. 在视频下方的工具栏中找到"加载字幕"按钮（位于"三连"那一行）
3. 点击按钮，选择本地的字幕文件
4. 字幕会自动跟随视频播放显示

## 支持的字幕格式

| 格式 | 说明 |
|------|------|
| `.srt` | SubRip 字幕，最常见 |
| `.ass` | Advanced SubStation Alpha，支持样式 |
| `.vtt` | WebVTT，网页字幕格式 |

> 注：目前只解析字幕文本内容，ASS 的复杂样式（字体、颜色、特效）暂不支持。

## 常见问题

**Q：按钮没有出现？**
A：请刷新页面。如果仍未出现，可能是 B 站页面结构更新，欢迎提交 Issue。

**Q：字幕显示位置不对？**
A：字幕默认显示在视频底部上方 80px 处，如需调整可修改脚本中的 `bottom` 值。

**Q：支持自动生成字幕吗？**
A：本脚本只负责"加载"已有字幕文件。如果需要从音频生成字幕，可以先用其他语音转文字工具生成 SRT 文件，再用本脚本加载。
